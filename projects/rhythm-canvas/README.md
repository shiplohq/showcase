# Rhythm Canvas

> Shiplo Showcase #17 — A browser-native rhythm visualizer: load a local audio
> loop, pick a visual mode and tap accents on the beat.

**Live demo:** https://rhythm-canvas.shiplo.site
**Category:** creative-tool · **License:** Apache-2.0 (original work)

Rhythm Canvas is a kinetic Swiss poster that plays. Pick one of three
synthesized loops, watch the beat grid draw itself in one of three visual
modes — Pulse, Orbit or Type — and tap anywhere to throw your own accents on
top. Nothing leaves the browser: the loops are generated by the Web Audio API
from a small JSON score, the visuals follow the same precomputed beat array
that schedules the drums, and there is no microphone, server or network call
after load.

## Highlights

- **One deterministic clock** — sound and pixels both derive from
  `beats[]` in `data/tracks.json` plus the `AudioContext` timeline, so the
  canvas never drifts from the speakers; pausing and seeking are frame-exact.
- **Three beat-locked modes** — Pulse (concentric rings on a step dial),
  Orbit (beats travelling concentric laps, one per bar) and Type (poster
  typography landing on every downbeat). Section choreography switches modes
  automatically; your manual pick wins until the next section.
- **Synthesized, license-clean audio** — kick, snare, hat, bass and pluck
  voices are oscillators and a generated noise buffer; no audio files, no
  downloads, no microphone.
- **Real reduced-motion mode** — the stage becomes a static poster with a
  progress bar and discrete beat indicators (not just a media query: a
  manual toggle persists alongside the OS preference).
- **Kinetic Swiss poster art direction** — black-tinted navy, warm white
  ink, signal red for the machine's beat, acid-lime reserved for human
  actions (taps, focus, manual overrides).

## Demo path (2 minutes)

1. Press **PLAY** (or Space) — the loop starts and the dial begins to breathe.
2. Tap the stage a few times **on the beat** — lime accents ring at your
   fingertips, with a short synth ping.
3. Press **2**, then **3** — the same beat data re-lenses through Orbit and
   Type. Press **1** to come back; the chip in the mode rail shows when the
   JSON choreography is driving (AUTO) vs your choice (MANUAL).
4. Click the track button (bottom-left) to cycle to **Acid Corridor 120 BPM**
   and **Half-Time Harbor 72 BPM**.
5. Drag the progress rail, drag volume, press **M** to mute, open **INFO** for
   shortcuts and the client-only note.
6. Toggle **MOTION REDUCED** — the poster freezes into a static print with a
   progress bar and discrete beat lamp; audio keeps playing.

## Development

```bash
npm install
npm run dev      # vite dev server
npm run build    # tsc -b + vite build → dist/
npm run preview  # serve the production build locally
```

## Deploying to Shiplo

`dist/` is a fully static artifact (relative base, no runtime CDN, no
backend). Deploy the folder to Shiplo static hosting:

```bash
npm run build
# then upload/point Shiplo at the dist/ directory (see repo DEPLOYMENT docs)
```

Verification: from the repo root, `npm run verify:static -- rhythm-canvas`.

```text
rhythm-canvas/

│   ├── features/

│   │   └── visuals/stage.ts       # canvas renderers (pure functions of the clock)
│   ├── lib/                       # gsap wrapper, data loader, prefs, motion state
│   └── styles/                    # tokens / base / motion
├── showcase/
│   ├── cover.webp / desktop.webp / tablet.webp / mobile.webp
│   ├── metadata.json
│   └── deployment.json
└── dist/                          # generated, gitignored — the deploy artifact
```

Adding a loop = adding a track object to `public/data/tracks.json`
(bpm, beats, sections, 16-step patterns, tokens) — no code changes.

## Keyboard

| Key | Action |
|---|---|
| Space | play / pause |
| 1 / 2 / 3 | mode — Pulse / Orbit / Type |
| T | tap accent at stage center |
| M | mute |
| ← / → | seek one beat |
| Home / End | loop start / end |
| Esc | close the info panel |
