What to record here:

- **npm dependencies bundled into build output** (runtime deps). Dev-only
  tooling does not need a row.
- **Fonts** — always; record the license (OFL, Apache, MIT, …).
- **Icons, images, illustrations, audio, textures** — always; "free
  download" is not a license.
- **Copied code snippets** — source URL + license of the source.
- **Vendored JS/CSS** — upstream repo, exact version, upstream license.
- **SVG assets from external sources** — artwork license plus any embedded
  content licenses.
- **AI-generated assets** — the generating tool, its terms allowing
  commercial redistribution, generation date.

Rules:

- Preserve upstream copyright and license notices; never add Shiplo
  headers to third-party files.
- Do not ship material with unknown, missing, non-commercial or
  no-derivatives licensing.
- This file must contain no placeholder rows at publication.
